ORIGINAL ESSAY HEADLINE
Computer Scientists Demonstrate First Self-Replicating Autonomous AI Worms in Networked Agent Systems
SPEED
※文クリックで音声再生

Cybersecurity researchers have developed proof-of-concept malware demonstrating that networked artificial intelligence agents can be hijacked by self-replicating adversarial worms. Dubbed 'Morris II' in homage to the historic 1988 internet worm, the malicious prompt payload exploits indirect prompt injection vulnerabilities to propagate autonomously between interconnected systems.

Once ingested by an automated email assistant or customer support bot, the worm forces the host model to exfiltrate private user data before forwarding the infection to adjacent agents. Security analysts caution that as enterprises aggressively delegate administrative tasks to autonomous multi-agent pipelines, unvetted semantic communications become high-risk attack surfaces. Software engineers insist that establishing deterministic isolation boundaries and zero-trust verification between autonomous agents is essential to prevent cascading systemic collapse.

【日本語全訳】

サイバーセキュリティ研究者らは、ネットワーク接続された人工知能エージェントが、自己複製する敵対的ワームによって乗っ取られ得ることを実証する概念実証マルウェアを開発した。 歴史的な1988年のインターネットワームにちなんで「モリス2」と名付けられたこの悪意あるプロンプト攻撃コードは、間接的プロンプトインジェクションの脆弱性を突いて相互接続システム間を自律的に増殖する。

電子メール自動アシスタントやカスタマーサポートボットに一度読み込まれると、このワームはホストモデルを操ってユーザーの個人データを外部に漏洩させ、隣接する他のエージェントへ感染を転送する。 セキュリティアナリストらは、企業が自律型マルチエージェントパイプラインに業務管理タスクを積極的に委任するにつれ、検証されていない意味的通信が極めて危険な攻撃対象領域（アタックサーフェス）になると警告している。 ソフトウェアエンジニアらは、自律エージェント間に決定論的な隔離境界とゼロトラスト検証を確立することこそが、連鎖的なシステム崩壊を防止するために不可欠であると主張している。

■ 構文・文法徹底解説（Syntax & Rhetoric）

Once 接続詞節による条件・時系列表現 「[Once ingested by an automated email assistant], the worm forces the host model to exfiltrate data」

Once + 過去分詞（ひとたび〜されると）が副詞節を構成し、AIアシスタントがメールを読み込んだ瞬間に攻撃が自動発動する様子を描写しています。

as + S + V（〜するにつれて：比例変化） 「[as enterprises aggressively delegate administrative tasks to multi-agent pipelines], communications become high-risk」

as（比例の接続詞）が、企業におけるAIエージェント導入の拡大と、それに伴うセキュリティリスクの高まりを連動させて表現しています。
